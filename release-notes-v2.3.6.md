# Osmium v2.3.6

Local multi-tag account organization.

## Added

- Create, rename, recolor and delete local tags.
- Assign multiple tags to an account.
- Filter the account list by all tags or uncategorized accounts.
- Search and tag filters work together.
- Tag metadata is included in encrypted vault backups.
- Existing v2.3.5 databases and older vault files remain readable.

## Notes

- Tag names are limited to 20 Unicode code points and are case-insensitive for duplicates.
- Colors are preset Material-friendly accents; no network access is added.
- This build is for testing first. No GitHub Release is created until device testing is approved.
