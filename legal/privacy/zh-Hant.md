# 隱私權政策

*生效日期：2026 年 11 月 11 日 · 適用於 Osmium v2.6.5.2 及後續版本*

*本頁為當前版本：發布於 osmium.im。當你在「關於」中開啟本文件時，應用程式會讀取它。*

Osmium 不會為廣告或分析之目的收集、販售或使用個人資料。沒有帳號系統、沒有註冊、沒有廣告 SDK，也沒有當機回報機制，更沒有 Osmium 雲端帳號或同步伺服器。每個版本首次開啟時會顯示歡迎頁，說明應用程式並詢問是否檢查更新；在你確認該歡迎頁（或之後在設定中開啟）之前，應用程式在啟動時不發起任何網路請求。

儲存：驗證器金鑰、帳戶名稱、服務商、標籤與標籤顏色僅儲存在本裝置上，並以不可匯出的 Android Keystore 金鑰進行 AES-256-GCM 加密。匯出的備份以你的密碼加密（PBKDF2-HMAC-SHA256，進行 120,000 次迭代後再以 AES-256-GCM 加密）。WebDAV 的登入資訊與自動備份密碼儲存在本機，並以 Keystore 金鑰加密。若你開啟開發者模式的明文匯出，匯出的檔案不加密：它以可讀形式包含你的全部金鑰，僅靠你存放它的位置提供保護。

裝置完整性：應用程式啟動時會在本機檢查裝置——啟動初期的早期快照、系統／掛載／核心／開機狀態／應用程式簽章等檢查、這些檢查之間的交叉核對，以及硬體層級的金鑰證明（TEE 憑證鏈、已驗證開機鏈與 boot hash）——後者使用內建於應用程式中的 Google 根憑證、由 Google 官方驗證器在本機完成驗證。Root 管理器偵測只向 Android 查詢一份固定的已知 Root 管理器套件名稱清單；應用程式不會列舉你裝置上安裝的應用程式。以上檢查全部在本機進行，不發起任何網路請求，結果也不會被儲存或傳送——它們只顯示在完整性頁面；當結果為可疑或已失陷時，每次開啟應用程式會提醒一次。裝置上裝有 Root 管理器應用程式僅視為提示，不構成證明。檢測詳細日誌預設關閉，只有你在開發者模式中開啟後才會寫入本機日誌。開發者模式可以隱藏此功能；一旦隱藏，應用程式不再於啟動時執行這些檢查，也不再顯示提醒。

證明撤銷資料：應用程式內建一份建置時取得的 Google 證明撤銷狀態清單快照。當你在完整性頁面點擊重新整理時，應用程式會從 https://android.googleapis.com/attestation/status 下載一份新副本並存入應用程式的私有儲存空間，且僅在下載內容解析成功之後才會取代先前的副本。該請求不攜帶任何帳號、驗證器或裝置資料；如同任何 HTTP 請求，伺服器會看到連線的常見中繼資料，例如你的 IP 位址。若重新整理失敗或你的網路封鎖它，先前的資料會繼續沿用，證明驗證仍可完全離線進行。

匯出：匯出到其它驗證器完全在本機完成。你要麼把明文檔案存到你選擇的位置（otpauth 連結、Aegis JSON 或 KeePassXC CSV），要麼——選擇 Google Authenticator 時——應用只把選取的帳戶繪製成螢幕上的二維碼，不寫入任何檔案。整個過程不上傳、不連線任何伺服器。明文匯出無需任何密碼即可讀取，請在完成轉移後刪除該檔案或關閉頁面。

字體：可選介面字體（Literata）內建於應用並離線繪製；選擇該字體不會發起任何網路請求，也不收集任何資訊。


匯入：從 Google Authenticator 二維碼以及 Aegis、2FAS、Raivo OTP 匯出檔案匯入，全部在本機完成。所選檔案會被讀入記憶體以建立匯入預覽；不會被複製、上傳或傳送到任何地方。只有你確認的項目會存入加密保險庫，其餘全部捨棄。若備份檔案中的項目使用了應用程式無法忠實重現的驗證碼參數（位數或演算法不在支援範圍內），該檔案會被整份拒絕，因此損壞或被修改的檔案永遠不可能加入一個會顯示服務端拒絕之驗證碼的帳戶。

網路：應用程式僅在下列情況建立連線：（1）法律文件——當你在「關於」中開啟《使用者條款》或《隱私權政策》時，從 osmium.im 讀取當前版本，最多每 10 分鐘一次，並保留已讀取的副本供離線查看；（2）向 GitHub Releases API 與 osmium.im 上發布的版本檔案（release.json、release-preview.json）發起版本檢查——在每個版本首次開啟時的歡迎頁詢問一次（其中正式版通道預先勾選、預覽版通道不勾選），兩者隨時可在設定中更改——開啟後會在你使用應用程式期間於背景進行（包含啟動時）；（3）WebDAV——在你啟用自動備份或開始備份時，連線你設定的位址；（4）LAN 快速傳輸——在傳輸畫面開啟期間連線另一台裝置；（5）上文的撤銷資料重新整理——僅在你手動點擊時發起；以及（6）開啟連結——將位址交給你的瀏覽器或應用程式商店。這些請求都不會攜帶你的帳戶、金鑰或裝置識別資訊。

法律文件：當你在「關於」中開啟《使用者條款》或《隱私權政策》時，應用程式會從 osmium.im 取得當前版本，確保你看到的始終是當前生效的版本。這些請求不攜帶任何帳號、驗證器或裝置資料。若讀取失敗，應用程式會顯示失敗提示，並提供前往官網的連結，上次讀取的副本仍可查看。

版本檢查：設定中提供兩個獨立開關——正式版與預覽版——它們不會在你不知情時開啟，而是在每個版本首次開啟的歡迎頁上詢問一次：其中正式版開關預先勾選，預覽版開關不勾選。每個已開啟的開關都會查詢兩個彼此獨立的來源，這樣一個來源被封鎖時，連線正常也不會被誤判為檢查失敗。只開啟正式版時，應用程式會請求 https://api.github.com/repos/lihongxi-g/osmium-authenticator/releases/latest 與 https://osmium.im/release.json，判斷是否有更新的正式版本；開啟預覽版時，則請求 https://api.github.com/repos/lihongxi-g/osmium-authenticator/releases 的發布清單與 https://osmium.im/release-preview.json，並在已開啟開關允許的範圍內選出最新版本——預覽版即開發者在 GitHub 上標記為 pre-release 的版本，osmium.im 上的預覽清單與其中最新的一個保持一致。這些請求只送出包含應用程式名稱與版本的 User-Agent；不傳送帳號、驗證器或裝置資料。任一來源發現新版本時，應用程式會顯示提示並提供前往下載頁的入口；來源正常回應且沒有新版本時保持靜默；只有所有被查詢的來源都失敗時，應用程式才會提示檢查更新失敗。兩個開關都可隨時在設定中關閉；兩者都關閉時，應用程式不再發起任何版本檢查請求。

LAN 快速傳輸：兩台裝置必須位於同一 Wi-Fi 網路，接收方只接受能證明螢幕上所顯示 12 位配對碼的發送方。握手期間，兩台裝置會交換手機型號名稱、安裝應用程式時產生的隨機識別碼（絕不源自任何硬體識別碼）以及下文所述的風險代碼，這些都會被綁定在加密會話中。在傳輸任何內容之前，每台裝置都會在本機掃描自己的網路鏈路以提示風險：讀取系統 ARP 表（/proc/net/arp，在系統允許的前提下；較新的 Android 版本會隱藏該表，此時這些偵測不會執行，應用程式會如實說明）、Wi-Fi 鏈路的安全類型與網路名稱、是否設定了 HTTP 代理、是否有 VPN 處於活動狀態，以及預設閘道的硬體位址。只有得出的風險代碼——絕不包含原始細節——會傳送給另一台裝置，且必須雙方都確認後才會傳送或接受任何帳戶資料。若你拒絕某台裝置，它會被記入一份保留 24 小時的封鎖清單，以加密形式存放在應用程式的私有儲存空間中。傳輸相關的任何內容都不會傳送給開發者或任何伺服器。該碼也可以顯示為 QR 碼，由發送方裝置以本機相機辨識，影像只在該裝置上處理、不會離開。若你把配對碼複製到剪貼簿，Osmium 會將其標記為敏感內容以免系統預覽，但不會事後自動清除剪貼簿，請只貼到你確實要使用的地方。

自動備份使用 Android 系統排程，可能因廠商的省電策略而延遲。備份會以加密檔案寫入你設定的 WebDAV 伺服器或 Download/Osmium 資料夾（預設保留最新 5 份，最多可設定 10 份；較舊的檔案會被清除）。你選擇的時間點會依裝置本身的時區解讀。相機掃描、二維碼讀取與生物辨識由 Android 在本機處理。Wi-Fi 狀態與多播僅在傳輸畫面開啟期間用於 LAN 裝置探索。WRITE_EXTERNAL_STORAGE 僅適用於 Android 8/9 上的自動備份。在 Android 17 及更高版本上，應用程式會在 LAN 傳輸、連線你自己網路中的 WebDAV 伺服器，或向這類伺服器自動備份之前，申請區域網路權限（ACCESS_LOCAL_NETWORK，屬於「附近的裝置」權限群組）；若你拒絕，這些功能將無法使用，應用程式會提供前往系統設定的捷徑。

通知與診斷記錄：自動備份透過 Android 本機通知回報結果——成功時靜默，失敗或被略過時提醒，鎖定畫面上只顯示「背景工作完成」。通知在 Android 13 及以上版本需要系統通知權限，可隨時在設定中關閉，且不會傳送給任何伺服器。應用程式也會把診斷記錄寫入應用程式私有儲存空間（一份輪替檔案，與記憶體中的副本並存），用於排查排程備份未執行的問題；它記錄排程、喚醒、結果與錯誤訊息，不記錄金鑰、驗證碼、PIN 或備份密碼。該記錄不會被傳送：只有你在「關於」中匯出時才會複製到剪貼簿，是否分享由你決定。完整性偵測的詳細記錄仍預設關閉，只有你在開發者模式中開啟後才會記錄。
