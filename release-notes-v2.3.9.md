# Osmium v2.3.9

## 中文
- 修复主页和设置页返回后滚动位置跳回顶部的问题。
- 新增标签功能开关二级页面。
- 未创建标签时不显示 `Uncategorized`。
- 标签支持调色盘和自定义 `#RRGGBB` 颜色。
- 关闭标签功能后，主页、账户编辑页和标签管理内容均不显示标签。

## English
- Preserve home and settings scroll positions when returning from child screens.
- Add a second-level tag settings page with a tag feature switch.
- Hide `Uncategorized` when no tags have been created.
- Add a muted color palette and custom `#RRGGBB` tag colors.
- When tags are disabled, hide tag UI from the home screen, account editor, and tag management content.
