# Third-party fonts

Osmium bundles two optional interface faces. Both are licensed under the
**SIL Open Font License, Version 1.1**, which permits bundling and
redistribution inside an application as long as the copyright notice and the
licence travel with the font.

The three Latin faces are redistributed **byte-for-byte as published**, with
only the file name lowercased (`Name[axis].ttf` → `name.ttf`), because Android
resource names must be lowercase `[a-z0-9_]`. Renaming the file is not a
modification of the font software, so the Reserved Font Names stay untouched.

The Chinese face is a **subset** built from the published variable font (see
below). OFL 1.1 permits subsets, and the reserved name may be used for a
subset that is otherwise unmodified. The subset is generated by
`scripts/build_han_serif_subset.py`, so it is reproducible from the upstream
file.

| App label | Files (`app/src/main/res/font/`) | Sizes | Scripts |
|---|---|---|---|
| Lora | `lora` (400), `lora_medium` (500), `lora_semibold` (600), `lora_bold` (700) | 207 / 132 / 132 / 132 KB | latin, latin-ext, cyrillic, cyrillic-ext, vietnamese |
| Literata | `literata` (400), `literata_medium` (500), `literata_semibold` (600), `literata_bold` (700), `literata_extrabold` (800), `literata_black` (900) | 933 / 525 / 525 / 524 / 523 / 503 KB | latin, latin-ext, cyrillic, cyrillic-ext, greek, greek-ext, vietnamese |

Measured from the shipped files: Lora 778 code points, Literata 1163. **Neither has CJK, Hangul or Devanagari**, so Chinese, Japanese,
Korean and Hindi text renders with the system font. A Chinese face was bundled
in an earlier revision of this branch and dropped again: its subset files alone
weighed 12 MB, and the app explains the gap on the font page instead (with a
shortcut to the language setting).

## Static instances

Each face ships fixed weight files, not the published variable font. The
instances were generated with `fontTools.varLib.instancer` at the weights the
app declares; the Noto Serif SC ones come out of
`scripts/build_han_serif_subset.py`, so they are reproducible. Weights above a
face's heaviest file are synthesised by the platform, which is why the CJK face
needs only regular + bold.

## Why these two

- **Lora** — a warm, slightly calligraphic serif.
  included.
- **Literata** — drawn for screen reading; the sturdiest Latin face at 11–16 sp.


Only one face is applied at a time, and the platform font stays the default.
Verification codes ignore all of them and stay monospace.
